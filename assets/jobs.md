## 魔法抗性 + 暴擊率 (job 0x01..0x1A)

職業 0x00 (龍) 沒有魔抗 / 暴擊率資料。`job_magic_resist_table @ 0x51F96`
為 dword[27]；`job_crit_table @ 0x5239B` 為 byte[27]。

魔法抗性公式：`抗性 = (10 - 數值) / 10`。例如 7 表示 30% 抗性。

## 轉職物品

部分職業需要特定道具才能轉職：

| 物品 | 編號 | 對應轉職 |
|---|---|---|
| 聖者之戒 | 0x58 | 僧侶、法師 → 聖者 |
| 勇者徽章 | 0x59 | 索爾 → 英雄 |
| 精靈契印 | 0x5A | 悠妮 → 召喚師 |
| 領悟之書 | 0x5B | 武者 → 武聖 |
| 心眼之書 | 0x5C | 弓兵 → 神射手 |
| 白金徽章 | 0x5D | 戰士 → 魔戰士 |
| 飛龍卵 | 0xCD | 騎士 → 龍騎士 |
| 控制中樞 | 0xD0 | 使渥德加入 |
