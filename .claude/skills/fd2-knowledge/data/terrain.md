# 地形影響

來源：`Strategy_Guide/introductions.htm`

```
地形影響
HIT = 使用武器的擊中率，會受武器影響
EV = 閃避敵方攻擊的能力，會受護甲影響
AP = 攻擊力，會受武器影響
DP = 防禦力，會受護甲影響

地形：

1.移動力影響

地形               步行   騎兵   飛行
------------------------------------------
一般（草地、平地）  -1     -1     -1
森林                -1     -2     -1
沼澤                -2     -3     -1

2.攻防影響

地形               攻擊力AP  防禦力DP
------------------------------------------
一般（草地、平地）   +5%       -5%
森林                 -5%      +10%
沼澤                 -5%       -5%
```
